# PerfectPixel Skill (for external distribution)

This packages the **same** sprite generation pipeline as the installable PerfectPixel
desktop app into a Claude Code skill. From a single line of text, it creates a
character plus motion animations and an 8-direction set, then exports them as a
game-engine-ready bundle.

Internally it drives the headless CLI `ppgen` (`cmd/ppgen`), which reproduces the app's
`GenerateState` + `ExportProject` logic without any GUI dialogs.

## Structure (plugin layout)

```
.claude-plugin/marketplace.json            Repository = marketplace manifest (repo root)
skill/perfectpixel/                         Plugin root
  .claude-plugin/plugin.json                Plugin manifest
  README.md
  skills/perfectpixel/                       The actual skill
    SKILL.md                                 Skill definition + Claude execution instructions (user-invocable)
    scripts/install.sh                       ppgen install (prebuilt download → source build fallback)
    reference/
      presets.md                             Catalog of 100+ motion presets
      providers.md                           Providers · models · environment variables · styles
    bin/ppgen                                Install artifact (generated by install.sh, untracked by git)
    .src/                                     Source clone cache (untracked by git)
```

## Installation (external users)

### A. Marketplace plugin (recommended)

In a Claude Code session:

```
/plugin marketplace add gykim80/perfectpixel-studio
/plugin install perfectpixel@perfectpixel-studio
```

After installing, invoke it with `/perfectpixel` or a natural-language request
("make walk/attack sprites for a knight character"). On the first invocation,
`install.sh` downloads a prebuilt `ppgen` matching your OS/arch from GitHub Releases
(no Go required). If no release exists or the network is blocked, it falls back to a
Go source build.

### B. Copy directly as a personal skill

```bash
# Copy just the skill folder (works without the plugin manifest)
cp -R skill/perfectpixel/skills/perfectpixel ~/.claude/skills/perfectpixel
bash ~/.claude/skills/perfectpixel/scripts/install.sh   # install ppgen

# Set the API key (pick one)
export GEMINI_API_KEY=...                 # environment variable, or
#   ~/.config/perfectpixel/config.json    # share the installed app's settings, or
#   .env in the working folder            # a single line: GEMINI_API_KEY=...
```

### C. Use the CLI directly

```bash
skills/perfectpixel/bin/ppgen \
  -desc "a small knight with silver armor" \
  -style pixel \
  -states "idle,walk,run,attack" \
  -dirset walk \
  -out ./knight-sprites \
  -json
```

## ppgen flag summary

| Flag | Description |
|---|---|
| `-desc` | Character description (English recommended) |
| `-style` | `pixel` (default) / `chibi` / `cartoon` / `retro16` |
| `-states` | Comma-separated state keys (see `reference/presets.md`) |
| `-percat N` | Auto-select N per category |
| `-all` | All presets (100+, expensive) |
| `-dirset KEY` | Also generate an 8-direction set for one state |
| `-out DIR` | Output directory (default `./perfectpixel-out`) |
| `-provider` / `-key` / `-model` | Force a specific provider/key/model |
| `-attempts N` | Quality-correction retries per state (default 3) |
| `-timeout` | Overall timeout (default 30m) |
| `-json` | Print only the result-summary JSON to stdout (for scripts/skills) |
| `-dump` | Print the preset/direction/style/provider catalog, then exit |

## Outputs

The `-out` directory will contain `base.png`, `sprite-sheet.png`, `manifest.json`
(PerfectPixel schema v2), `sprite-sheet.json` (Aseprite-compatible),
`frames/<state>/frame-NN.png`, `gif/<state>.gif`, and `apng/<state>.png`. Most game
engines import the `sprite-sheet.png` + `sprite-sheet.json` pair (the Aseprite importer
in Phaser / Unity / Godot).

## Releasing (for maintainers)

Prebuilt binaries are produced by GitHub Actions (`.github/workflows/release-ppgen.yml`).
Pushing a version tag cross-compiles `ppgen-<os>-<arch>` for darwin/linux (amd64·arm64)
plus windows (amd64) and attaches them to the release.

```bash
git tag v1.0.0
git push origin v1.0.0   # → runs the release-ppgen workflow and attaches assets
```

After that, a user's `install.sh` fetches `releases/latest/download/ppgen-<os>-<arch>`
and installs without Go. You can pin a specific version with `PP_VERSION=v1.0.0`, or
set `PP_BUILD=1` to skip the download and always build from source.

Updating the marketplace: when the skill/plugin contents change, bump `version` in
`skill/perfectpixel/.claude-plugin/plugin.json` and push. Users refresh with
`/plugin marketplace update perfectpixel-studio`.

## Relationship to the installable app

The skill and the app share the same Go code (`internal/sprite`, `internal/gen`,
`internal/config`). When an algorithm is improved, both the app and the skill pick it up
identically, and the prebuilt `ppgen` is updated via a new release tag (or `install.sh`
rebuilds from the latest source).
